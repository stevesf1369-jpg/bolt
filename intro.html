Local LLM via Ollama

Step 1. Install Ollama

If you haven't installed Ollama yet, go to the ollama homepage and install.
Visit Ollama Download Page

Step 2. Download Qwen

qwen2.5-coder:32b (20GB) qwen2.5-coder:14b (9GB) qwen2.5-coder:7b (4.7GB) qwen2.5-coder:3b (1.9GB) qwen2.5-coder:1.5b (986MB) qwen2.5-coder:0.5b (531MB)

Step 3. Restart Bolt

Restart Bolt and select "Ollama". You should see Qwen.

Free LLM APIs via Github

GitHub provides FREE API access to gpt-4o and gpt-4o-mini (Rate limited). All you need to do is set up the API key.

Step 1. Get Github API Key

Get API Key from GitHub

Step 2. Connect API Key

Go to the Configure tab and enter the API key, and save

Step 3. Restart Bolt

Restart Bolt and select "OpenAILike". You should see gpt4-o

LLM APIs

Directly get API keys from each LLM API provider.

Step 1. Get API Key

Go get an API key from any LLM provider. Supported LLMs
  1. Groq
  2. OpenAI
  3. Anthropic
  4. Openrouter
  5. Google
  6. Deepseek
  7. Mistral

Step 2. Connect API Key

Go to the Configure tab and enter the API key, and save

Step 3. Restart Bolt

Restart Bolt and select the LLM provider and get started!

Build mode prompt

Build a polished, frontend-only mini web app. Keep the scope small and make the core interaction work end to end. Use the existing frontend stack and run entirely in the browser—no server, database, authentication, external API, or environment secrets. Persist user data locally when useful. Make it responsive, accessible, and cohesive, with thoughtful empty, loading, and success states. Avoid placeholder controls: every visible interaction should work. Start by briefly describing the app and its main interaction, then implement it and verify it runs.
